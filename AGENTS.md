# Omoikane — agent operating manual

You maintain this wiki. The human curates sources and asks questions; you write every page under `wiki/`.

## Layout

- `raw/inbox/` — sources waiting for ingest. Read only.
- `raw/sources/` — ingested sources. Immutable. Never edit, never delete.
- `raw/assets/` — images downloaded by Obsidian. Read only.
- `wiki/sources/` — one page per ingested source.
- `wiki/entities/` — people, organisations, products, places.
- `wiki/concepts/` — ideas, methods, recurring themes, comparisons.
- `wiki/queries/` — filed answers to questions.
- `index.md` — generated by `python bin/wiki-index.py`. Never edit by hand.
- `log.md` — append-only chronology. Prefix every entry `## [YYYY-MM-DD] <op> | <title>`.
- `_review.md` — questions for the human: contradictions, ambiguous claims, missing sources.

## Page contract

Every page under `wiki/` starts with this frontmatter; `wiki-index.py` and `wiki-lint.py` depend on it:

```yaml
---
title: Exact page title
type: source | entity | concept | query
summary: One line, under 120 characters, used verbatim in index.md
tags: [tag-a, tag-b]
created: YYYY-MM-DD
updated: YYYY-MM-DD
sources: [wiki/sources/<slug>.md]   # pages this one draws from; empty list on source pages
---
```

- Filename is the kebab-case slug of `title`.
- Link pages with `[[slug]]` wikilinks. A claim taken from a source cites it inline: `(source: [[slug]])`.
- One entity or concept per page. A concept mentioned on three pages gets its own page.
- When a new source contradicts an existing claim, keep both in the page under `## Contradictions` and add an entry to `_review.md`. You do not pick a winner.

## Operations

Prompts live in `prompts/`; each is reachable as a slash command in Claude Code and OpenCode.

- Ingest a source: `prompts/ingest.md`.
- Answer a question and file it: `prompts/ask.md`.
- Semantic health check: `prompts/lint.md`.

After any operation that touches `wiki/`, finish with:

```
python bin/wiki-index.py
python bin/wiki-lint.py
```

`wiki-lint.py` exits non-zero on broken wikilinks, missing frontmatter or orphan pages. Fix every finding before you report done.
