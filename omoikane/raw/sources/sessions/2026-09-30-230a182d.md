## O que é a tarefa agendada

O loop do Omoikane tem duas metades:

- **Captura** (já funciona sozinha): o hook `Stop` do Claude Code grava cada sessão em `omoikane/raw/inbox/sessions/`.
- **Destilação** (não roda sozinha): alguém precisa executar `omoikane/bin/wiki-ingest.ps1`. Ele chama o Claude headless para cada arquivo do inbox: `/distill` para sessões, `/ingest` para fontes, e `/synthesize` a cada 5 distills. Hoje isso só acontece quando alguém roda o script à mão. A tarefa agendada (`install-schedule.ps1`) registra no Agendador de Tarefas do Windows a execução do `wiki-ingest.ps1` a cada N minutos. Sem ela, "cada sessão deixa o projeto mais inteligente" depende de você lembrar de rodar o script.
