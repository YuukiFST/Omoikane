# pstack is an Omoikane reference

> "Sim, pstack deve ser utilizado como referência https://github.com/cursor/plugins/tree/main/pstack existe muita conteudo valioso nessas skills"

Translation: "Yes, pstack must be used as a reference [URL]; there is a lot of valuable content in these skills."

What to update:

- `omoikane/wiki/domain/omoikane-references.md` lists three references (LLM Wiki, brainmaxxing, ai-memory). Add pstack, https://github.com/cursor/plugins/tree/main/pstack, as a fourth one, so the rule on that page ("read the reference that covers the same problem") covers its skills.
- Its "What Omoikane took from each, so far" section gets a pstack line: `/correct` gave the guard whose error names the fix (issue #98, PR #99, merged 2026-10-06); `/why` and `/recall` gave `/ask` reading `origin/main` history (issue #97, PR #100, open). Details are on `omoikane/wiki/entities/pstack.md`.
- `omoikane/wiki/entities/pstack.md` notes that pstack was read as the successor of brainmaxxing; it is now a reference in its own right, not only through brainmaxxing.
- The pstack skills already read (2026-10-05): `recall`, `reflect`, `correct`, `why`, `principle-encode-lessons-in-structure`, `poteto-mode`. The user says the other skills hold valuable content too; they have not been read for Omoikane yet.
