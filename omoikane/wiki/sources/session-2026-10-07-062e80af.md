## What it learned

- Every system now ships the development skills, with one budget and no opt-in: [[every-system-ships-the-development-skills]] (turns 3, 5).
- `omoikane-mode` is the counterpart of `poteto-mode`, with one router for the principles and a brief line in place of Cursor's `reminder:`: [[omoikane-mode-routes-each-task-to-a-playbook]] (turn 5).
- Pi sends `/skill:<name>` as a `<skill name=... location=...>` block, which the capture did not skip: [[pi-expands-a-skill-command-into-a-skill-block]] (turn 6).
- Pi loads loose Markdown in a skills folder as a skill, and does not load a nested `SKILL.md`; the spec first said the opposite: [[pi-loads-loose-markdown-in-a-skills-folder-as-a-skill]] (turn 9).
- Node on Windows defines neither `O_NOFOLLOW` nor `O_NONBLOCK`, so the Cloudflare validators refuse to run there: [[node-on-windows-lacks-o-nofollow-and-o-nonblock]] (turns 3, 8, 10).
- `new-system.py` moves the template's `LICENSE` to `omoikane/LICENSE`: [[new-system-starts-with-an-empty-memory]] (turn 9).
- A stack of PRs went stale against `main` and was checked as one integration: [[green-pr-ci-can-be-stale-against-the-current-main]] (turns 10, 11).
