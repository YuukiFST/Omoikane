## What it learned

- Joining the lines of an error message, or wrapping a capture line, before redaction let a secret through: [[reshaping-capture-text-before-redaction-leaks-secrets]] (turns 2, 3).
- A `.capture-redact` list in the ANSI code page broke the capture and then the record of that failure: [[capture-redaction-breaks-on-frontmatter-clips-and-encodings]] (turn 3).
- OpenCode's read tool cuts each line at 2,000 characters: [[opencode-read-tool-cuts-lines-at-2000-characters]] (turn 2).
- The `curl` and `mysql` secret patterns scanned to the end of the line, and took over 1 s a turn on a line of 20,000 characters: [[secret-redaction-patterns-leak-swallow-and-backtrack]] (turn 3).
- On Windows, `subprocess` in text mode wrote `\n` as `\r\n` on stdin, and a valid diff failed `git apply --check`: [[python-text-mode-stdin-writes-crlf-on-windows]] (turn 2).
- `git merge --no-commit` wants a committer identity, which the CI runner does not have: [[git-merge-no-commit-needs-a-committer-identity]] (turn 2).
- Scheduled runs set `OMOIKANE_NO_CAPTURE` (`wiki-ingest.ps1:32`) and the capture returns before it reads anything, so a headless run never writes `.capture-errors` (turn 2).
- The `escape-edit-guard.py` hook blocked a Python heredoc and a `sed -i`: [[python-heredoc-edits-corrupt-backslash-n]] (turn 2).
